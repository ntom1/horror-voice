# 怖い声変換ツール

お化け屋敷・ホラー演出用の、ブラウザだけで動く音声エフェクト型の怖い声変換ツールです。

iPhoneやPCで録音した声、または手元の音声・動画ファイルを読み込み、次の4種類のプリセットで変換できます。

- 鬼：低音、歪み、圧迫感
- お化け：残響、揺れ、遠くから聞こえる声
- 悪魔：複数の低音レイヤー、強い歪み
- 呪いのラジオ：電話・無線風、ノイズ、帯域制限

変換後の音声はブラウザ内で再生でき、WAVファイルとして保存できます。

## 特徴

- GitHub Pagesでそのまま公開できる静的Webアプリ
- `index.html` 単体で動作
- HTML / CSS / JavaScriptのみ
- npm、Node.js、ビルド工程、バックエンド、DB、外部APIは不要
- Tone.js（MIT License）と Web Audio API / MediaRecorder / OfflineAudioContextで端末内処理
- 音声はサーバーへ送信しない
- AI声質変換、声真似、ボイスクローンではなく、音声エフェクトによる変換

## 使い方

1. ブラウザで `index.html` を開く
2. 「録音開始」を押してマイクを許可する、または音声・動画ファイルを選択する
3. 「停止」を押すと、元音声を再生できる
4. プリセットを選ぶ
5. 「怖さ」スライダーを調整する
6. 「変換する」を押す
7. 変換後音声を再生し、「WAVを保存」で保存する

処理対象は負荷を抑えるため、最大60秒程度です。長い音声を読み込んだ場合は先頭60秒を処理します。

## GitHub Pagesでの公開方法

1. GitHubでリポジトリを作成する
2. `index.html` と `README.md` をリポジトリにpushする
3. GitHubのリポジトリ画面で `Settings` を開く
4. `Pages` を開く
5. `Source` を `Deploy from a branch` にする
6. `Branch` を `main`、フォルダを `/root` にする
7. 保存後、表示された公開URLにアクセスする

## iPhoneで使う場合の注意点

- マイク録音はHTTPS環境で使ってください
- GitHub Pagesの公開URLはHTTPSなので、マイク許可が動作する前提です
- `file://` で直接開いた場合、iPhoneではマイク録音が動かないことがあります
- 初回録音時にマイク許可を求められます
- 録音形式はブラウザ対応状況に合わせて `audio/mp4`、`audio/webm;codecs=opus`、`audio/webm`、`audio/ogg;codecs=opus` の順に試します
- 古いiOSでは録音や一部の音声形式の読み込みに制限がある場合があります

## プライバシー

このツールは外部APIを使いません。音声エフェクト処理には、ブラウザ上で動作するTone.js CDNを利用します。

録音・読み込み・変換・WAV保存はブラウザ内で完結します。音声ファイルや録音データをサーバーへ送信する処理はありません。

## 用途について

このツールは、お化け屋敷、展示、イベント、映像制作、音声演出などのホラー演出向けです。

特定個人の声を模倣する機能、なりすまし機能、AIボイスクローン機能はありません。

## 既知の制約

- Tone.js CDNを読み込めない環境では、内蔵のWeb Audio API処理へフォールバックします
- 長尺音声は端末負荷が高いため、処理対象は最大60秒程度です
- 変換は端末内で行うため、古いスマートフォンでは時間がかかる場合があります
- ブラウザがMediaRecorderやWeb Audio APIに対応していない場合、録音または変換ができません
- 読み込めるファイル形式はブラウザのデコード対応状況に依存します
- iPhoneではPCのようなドラッグ&ドロップではなく、ファイル選択または録音を使う想定です
